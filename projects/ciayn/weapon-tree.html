Tier 2 矩陣（元素 / 物理強化）

Tier 2 = Tier 1 base + 元素（#火/#冰/#雷/#毒）或物理強化。命名規則：{變體前綴}{Tier1 base 名}，前綴 = 火焰 / 冰霜 / 雷電 / 毒性 / 強化。共 192 格（非骨 36×5 + 骨 12×1，D9 骨製禁元素）。Tier 2 是純資料 archetype（generic detection，無專屬程式碼），只貢獻顯示名稱 + tier 分級。

144 個元素變體已 promote 進遊戲生效（✓）。48 個物理強化變體（◐）暫留 pending：其 4-tag match 與 Tier 0/1 base 完全相同，需未來 #強化 tag 才能在 detection 區分（tier-slot-matrix.md 標 deferred）。

武器進化路線圖

依基底武器類型分家族 · 只畫通往神器的路徑 · 2026-06-10

只畫「通往神器」的路線：T0→T1→T2（路線上的節點）→T3 神器 →T4→T5 派生。 邊上標示取得方式 —— 黃字 = 里程碑天賦、藍字 = 升級 modifier。 每家族另有大量不在神器路線上的 T2 變化形，以計數摘要呈現（完整清單見 database.html）。 tier = 與木棍的編輯距離；T4/T5 不是獨立 archetype，而是 D 天賦授予的 component signature。

所有路線都從 T0 木棍（#中等 #木製 #打擊 #揮舞）出發。shape tag 由 weapon_length 自動派生（#短小 <160 / #中等 160–250 / #長兵 250–400 / #巨大 ≥400）。

路線總表

T3 神器家族關鍵前置T4 → T5
鎮獄棒棍→杖鐵棍 + 長兵鎮獄迴旋棒 → 鎮獄・五行旋風
火/冰/雷/毒法杖棍→杖結晶短棒 + 元素賢者法杖 → 元素創世杖（共用）
火焰巨人錘鎚火焰鐵大錘火山巨人錘 → 遠古泰坦熔爐
飛雷錘鎚雷電鐵露營錘 + 投射雷神迴旋鎚 → 天雷神域鎚
名刀吹雪劍冰霜鐵大劍吹雪・刃風 → 吹雪・居合零式
毒針劍毒性結晶短劍 + 投射蝕毒爆針 → 瘴氣毒華
骸骨巨鐮斧骨製化 + 長兵冥府迴鐮 → 黃泉收割者
骨飛斧斧骨製化 + 短小 + 投射腥風骨旋 → 萬骨颶風

11 條 T3 路線全部可達（4 條法杖共用一套 T4/T5）。T4/T5 signature 共 16 個。巨神兵 / 巨斧（#巨化 巨化端）已於 2026-06-10 棄案移除。
